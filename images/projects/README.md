One image per project. The filenames referenced in `js/data.js` are:

    ai-customer-support.jpg

Recommendations:
- 16:10 ratio, around 1280 × 800 px, under ~250 KB each
- Best content: a screenshot of the actual workflow (n8n / Make canvas),
  a dashboard, or a clean diagram of the process
- Do not use stock photos that imply work you have not done

Missing files degrade gracefully to a navy placeholder tile — the layout
never breaks and no broken-image icon is shown.
