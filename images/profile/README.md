# images/profile/

Put your own portrait here.

Required filename (referenced from `js/data.js` → `personal.photo`):

    md-easin-bhuyian.jpg

Recommendations:
- Portrait orientation, around 800 × 1000 px
- JPG or WebP, compressed to under ~200 KB
- Plain or softly blurred background, professional clothing, good lighting

If the file is missing, the site automatically shows a clean "ME" placeholder
instead of a broken image. Never use a stock photo of another person.
