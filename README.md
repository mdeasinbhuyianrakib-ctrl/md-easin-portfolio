# MD Easin Bhuyian — AI Automation Engineer Portfolio

Cloudflare Pages-ready static portfolio.

## Deploy with Cloudflare Pages + GitHub

1. Create a GitHub repository named `md-easin-portfolio`.
2. Put the contents of this folder in the repository root.
3. In Cloudflare: Workers & Pages → Create application → Pages → Connect to Git.
4. Select the GitHub repository.
5. Production branch: `main`.
6. Build command: `exit 0`.
7. Build output directory: `.`

Cloudflare will deploy the top-level `index.html` and provide a `*.pages.dev` URL.

## Manual updates

Edit the `PORTFOLIO_DATA` object near the top of `index.html`.

Before publishing, replace:
- LinkedIn
- GitHub
- WhatsApp
- real experience
- real certifications
- real project status/results
- CV file
- portrait/project images

Never publish invented claims.
